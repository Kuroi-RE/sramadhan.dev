# Pengalaman dan Rekam Jejak Satria Ramadhan

Satria Ramadhan memiliki rekam jejak dalam merancang dan mengembangkan antarmuka sistem operasi berbasis peramban (Web OS), aplikasi audio interaktif, serta utilitas desktop.

## Rekam Jejak Proyek Utama

1. **sramadhan.cv (Portfolio Bergaya OS)**:
   - Platform portofolio interaktif desktop dalam web dengan alur Boot → Lockscreen → Welcome → Desktop.
   - Dilengkapi Window Manager berfitur drag/resize berbasis `react-rnd`, Dock dengan efek magnify spring, Notch PioPio, dan asisten AI terintegrasi.
   - Dibangun dengan Next.js 16, React 19, Tailwind CSS v4, dan bilingual support (ID/EN).

2. **PioPio Notch**:
   - Aplikasi Dynamic Island desktop yang menampilkan visualisator audio spektrum real-time, lirik tersinkron Better Lyrics, pemantauan ring metrik sistem, dan maskot panda interaktif.
   - Dibuat dengan arsitektur modular dan komponen web modern.

3. **Audio & Media Integration**:
   - Berpengalaman dalam parsing format lirik LRC (multi-timestamp, offset, sync timing dengan binary search) dan pengolahan audio stream real-time menggunakan Web Audio API.
